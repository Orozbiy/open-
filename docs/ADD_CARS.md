# Жаңы машина кошуу

Машиналар `js/cars/cars.js` файлындагы `LIST` тизмесинде. Эки жол бар.

## 1. Сүрөттөн (шаблондон) өзүбүз куруу — процедуралык модель
Ар бир машина кесилиштер (станциялар) менен сүрөттөлөт: `[z, жарым-туурасы, асты, үстү]` — метр менен.
`z > 0` — машинанын алды, `z < 0` — арты. Сүрөттөгү каптал көрүнүштөн бийиктиктер, үстүнөн туурасы алынат.

```js
{
  id: 'my_car', name: 'Менин машинам', tag: 'Жаңы', price: 25000, len: 4.4,
  stats: { engine: 16, maxSpeed: 64, grip: 1.0, drift: 1.0, steer: 1.0, wheelbase: 2.6, pitch: 1.0 },
  nTub: 3.4, nCabin: 2.6,                       // бурчтардын тегиздиги (көбөйсө — бурчтуураак)
  tub:   [[2.1,.6,.3,.5], [1.5,.88,.2,.8], ... , [-2.1,.6,.3,.7]],          // кузов
  cabin: [[.9,.66,.78,.9,0], [.3,.62,.78,1.3,1], ... ],                      // кабина: акыркы сан 1 — төбө (боёк), 0 — айнек
  wheels: { fz: 1.3, rz: 1.25, fr: .33, rr: .35, fw: .24, rw: .3 },          // дөңгөлөк: алдыңкы/арткы z, радиус, туурасы
  rimStyle: { spokes: 5 },
  extras(c) { c.box(1.8,.05,.4, c.mats.dark, 0, 1.2, -2); }                   // спойлер, фара, чыгаруу түтүгү ж.б.
}
```
`c.box(w,h,d,материал,x,y,z)` жана `c.cyl(...)` менен майда деталдарды кошосуз. Материалдар: `paintFlat` (боёк), `dark`, `chrome`, `head`, `tail`, `amber`, `white`.
Өзгөрткөндөн кийин браузерди жаңыртыңыз — Гаражта көрүнөт.

## 2. Даяр 3D модель (.glb)
Сүрөттөн дароо мыкты 3D керек болсо: image-to-3D кызматтары (Meshy, Tripo, Hunyuan3D ж.б.) .glb чыгарат, же Sketchfab'тан лицензиясы ылайыктуусун жүктөңүз.
1. Файлды `assets/models/` ичине салыңыз.
2. `cars.js` ичинде (же `index.html` аягында) каттаңыз:
```js
TK.Cars.register({ id: 'nsx', name: 'Менин NSX', price: 50000, len: 4.4, yaw: 0,
  glb: 'assets/models/nsx.glb', stats: { engine: 18, maxSpeed: 68 } });
```
- Модель `len` метрге автоматтык масштабдалат; багыт туура болбосо `yaw: Math.PI` (же ±Math.PI/2) жазыңыз.
- Боёк алмашуусу үчүн кузовдун материалынын аты `paint`/`body` деп башталышы керек.
- Браузер файлдарды `file://` аркылуу жүктөбөйт — **Live Server** же `start-server.bat` менен ачыңыз.
- Дөңгөлөктөр бул режимде айланбайт (бир бүтүн модель).

## Лицензия боюнча эскертүү
Hum3D сыяктуу сайттардын сүрөттөрү/модельдери — сатыла турган продукт. Сүрөттү шаблон катары гана колдонобуз, оюнга текстура болуп кирбейт. Оюнду жарыялайм десеңиз, чыныгы бренд (Porsche ж.б.) аттарына/логотиптерине лицензия керек болушу мүмкүн.
